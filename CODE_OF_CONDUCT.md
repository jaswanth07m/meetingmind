# Code of Conduct

## Our Pledge

We are committed to creating a welcoming, respectful, and collaborative environment for everyone contributing to MeetingMind.

## Expected Behavior

* Be respectful and professional.
* Welcome constructive feedback.
* Collaborate openly with teammates.
* Focus on improving the project.

## Unacceptable Behavior

* Harassment or discrimination.
* Offensive language.
* Personal attacks.
* Sharing confidential information without permission.

## Enforcement

Project maintainers may remove contributions or restrict participation if these guidelines are violated.

## Scope

This Code of Conduct applies to all project discussions, commits, merge requests, and issue tracking.
