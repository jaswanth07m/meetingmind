# Contributing to MeetingMind

Thank you for contributing to MeetingMind!

## Getting Started

1. Fork the repository.
2. Clone the repository.
3. Create a new branch for your changes.
4. Make your changes and test them locally.
5. Commit using semantic commit messages.
6. Open a Merge Request.

## Development Guidelines

- Follow the existing project structure.
- Keep commits small and meaningful.
- Write clear commit messages.
- Ensure the project builds successfully before submitting.

## Commit Message Format

Examples:

feat: add offline transcription

fix: resolve SQLite storage issue

docs: update README

ci: add GitLab pipeline

## Pull Requests

Before submitting:

- Code builds successfully.
- Documentation is updated if necessary.
- CI pipeline passes.
- Offline functionality is not affected.

Thank you for helping improve MeetingMind!
